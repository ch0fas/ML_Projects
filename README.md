# Machine Learning Proyects

These projects and labs were worked on by **Sofía Maldonado García**, **Viviana Toledo**, **Diana Valdivia**, **Samantha Sanchez** and **Isabel Valladolid** for our Machine Learning course in Fall 2025 at ITESO

- **L2_CIFAR10** is an image classification problem with the CIFAR-10 dataset. For this project we used pre-trained neural networks for image recognition.
- **L3_StockExchange** uses RNNs and more standard Time Series algorithms to predict the price of a stock based on historical data, in this case Walmart's
- **P1_FashionMNIST** is like the CIFAR10 lab but with the Fashion MNIST dataset. This project is more thorough in explanations, image pre-processing and has better results.
- **P2_StyleTransfer** uses CNNs to apply the style of an image to another. Along with the Notebook explaining the process there's also a small app made with Gradio to test it with any images the user desires.
-  **P3_CIFAR10** is an unfinished improvement upon the Lab 2
-  **PFINAL_UrbanVideos** uses Yolo models to detect objects in videos we recorded.
